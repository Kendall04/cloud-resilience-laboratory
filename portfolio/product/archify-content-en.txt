ASG/E13 es autónomo; no depende de Sentinel. No se demuestra failover automático de una AZ a la otra.|NAT instance recovery operates independently of Sentinel. Automatic failover between AZs was not demonstrated.
Ambos servicios ECS reciben las subnets privadas A y B: su colocación no queda fijada a un color ni a una AZ. SQL es un único escritor en B.|Both ECS services can use private subnets A and B. Placement is not tied to a color or AZ. SQL has a single writer in B.
Antes de promover: la cohorte exacta pasa /ready con SQL/KMS. Tras promover: se prueba /ready por la ruta real API Gateway → ALB.|Before promotion, the exact cohort passes /ready with SQL/KMS. After promotion, /ready is checked through API Gateway → ALB.
Cada subnet pública tiene ruta al IGW. Cada ruta privada apunta a la ENI de su propia NAT; la EIP pertenece al egreso de esa NAT.|Each public subnet routes to the Internet Gateway. Each private route points to its own NAT ENI, whose EIP handles egress.
Cambios solo documentales: scope omite build/publicación/despliegue. PROD implementado, deshabilitado, no instalado ni validado.|Documentation-only changes skip build, publication, and deployment. PROD is implemented and disabled, and was never installed or validated.
CloudFront DEMO es independiente del runtime; Sentinel solo permanece en Historia. PROD no está instalado ni validado.|The CloudFront DEMO runs independently of the runtime. Sentinel survives only in the historical record. PROD was never installed or validated.
DEV al 10 nov 2026. Una tarea activa y un SQL Express: no hay alta disponibilidad de base de datos.|DEV on November 10, 2026 had one active task and one SQL Express instance. The database was not highly available.
Dos NAT no implican SQL multizona ni múltiples tareas activas. DEV demostrado; PROD no instalado.|Two NAT instances do not imply multi-AZ SQL or multiple active tasks. DEV was demonstrated. PROD was never installed.
E13 repara EIP, ruta y source/destination checking (SDC desactivado) al reemplazar la instancia de cada ASG.|When an Auto Scaling group replaces a NAT instance, the recovery handlers restore its Elastic IP and route and disable source/destination checking (SDC).
El administrador del host conserva autoridad sobre SO y SQL; no se presenta ese acceso como aislamiento de un administrador comprometido. PROD no está instalado ni validado.|The host administrator retains authority over the OS and SQL. This does not provide isolation from a compromised administrator. PROD was never installed or validated.
El ensayo histórico restauró HTTPS en 2m29,191s. Es una medición puntual, no un SLA.|The dated trial restored HTTPS in 2m 29.191s. This is a point-in-time measurement, not an SLA.
El execution role inyecta el secreto al arrancar. Solo el task role de la API utiliza la CMK de texto.|The execution role injects the secret at startup. Only the API task role uses the text encryption key.
El execution role lee la versión aprobada del secreto y la inyecta al inicio; no es el task role que utiliza KMS durante las peticiones.|The execution role reads the approved secret version and injects it at startup. The separate task role uses KMS during requests.
